Rules

Do's & Don'ts

Always Do
Use Playfair Display for all headings and display text
Use CSS variables (e.g. var(--green)) — never hardcode colours
Apply transition: var(--transition) to all interactive elements
Make the header sticky (position: sticky; top: 0) on every page
Add .reveal + IntersectionObserver scroll animations to content sections
Use pill border-radius (999px) for all buttons and tags
Replicate the sidebar + overlay pattern for mobile nav on every page
Use Font Awesome 6 Free for all icons (fa-solid / fa-brands)
Include the scrolling motto strip between major content sections
Keep footer consistent — dark bg (#1a2e22) + 4 columns + social icons
Lift cards on hover: translateY(-6 to -8px) + --shadow-lg
Use clamp() for responsive font sizes in hero headings
Never Do
Don't use Arial, Roboto, Inter, or system-ui for any text
Don't hardcode hex colours — always reference CSS variables
Don't change the primary green (#2ecc71) to another hue
Don't use sharp corners on cards — minimum border-radius: 12px
Don't remove the overlay when the sidebar is open
Don't use square buttons — always pill-shaped (border-radius: 999px)
Don't animate with linear easing — use cubic-bezier(0.4,0,0.2,1)
Don't use purple, blue or red as a primary colour
Don't skip the sticky header — it must appear on every page
Don't use <table> for layout — use CSS Grid or Flexbox
Don't forget mobile breakpoints at 768px and 480px
Don't use Bootstrap classes — write custom CSS using the variables

When asking an AI to build a new page, paste the following at the start of your prompt:

Build a [PAGE NAME] page for Sterkspruit Junior Secondary School website.
Follow the design system exactly:
— Fonts: Playfair Display (headings, 700/900) + Source Sans 3 (body, 300/400/600/700)
— Primary colour: #2ecc71 (--green). Dark: #27ae60. Deep: #1a7a44. Footer bg: #1a2e22
— All CSS variables in :root (see design board)
— Sticky green header with logo, nav links, hamburger for mobile, sidebar + overlay
— All transitions: 0.35s cubic-bezier(0.4,0,0.2,1)
— Cards: white bg, 16px radius, box-shadow, lift on hover
— Buttons: pill-shaped (999px radius), green primary, translateY(-2px) on hover
— Tags: uppercase, 0.7rem, 700 weight, letter-spacing 0.18em
— IntersectionObserver scroll-reveal on all content sections (.reveal class)
— Footer: dark (#1a2e22), 4-column grid, green underline on headings, social icons
— Scrolling motto strip: "Forward Ever ◆ Backward Never" between sections
— Icons: Font Awesome 6 Free (fas / fab)
— Mobile breakpoints: 768px (tablet), 480px (mobile)
— No Bootstrap, no hardcoded colours, no Arial/Roboto/Inter fonts
